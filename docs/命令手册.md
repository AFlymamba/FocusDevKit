# fxdevkit 命令手册

> fxDevKit（fxdevkit）— 研发动作背后的插件化增强层。
> 本文档基于当前已实现命令（`@fxdevkit/cli` 0.1.0）逐条整理，命令示例来自真实终端输出。

---

## 零、安装（本地源码方式，不发布 npm）

> fxdevkit 目前**不发布到 npm registry**。用 `npm link` 把源码里的 CLI 链接到全局，本地直接使用，改代码即生效。

### 一次性安装

在你的终端（PowerShell 或 cmd，**注意是系统自带的 npm，不是任何 IDE 托管的 Node**）里执行：

```powershell
cd D:\products\devkit
npm install        # 首次安装依赖（依赖变化时重跑）
npm run build      # 编译所有包，生成 dist
cd packages\cli
npm link           # 把 @fxdevkit/cli 链接到全局，注册 fxdevkit 命令
```

验证：

```powershell
fxdevkit --version
# @fxdevkit/cli 0.1.0
```

### 日常开发循环（改了源码怎么生效）

`npm link` 指向的是源码目录，所以**不需要重复 link**。改了 `packages/*/src` 里的代码后：

```powershell
cd D:\products\devkit
npm run build      # 重新编译，dist 更新后命令立即生效
```

只有改了 `packages/cli/package.json` 的 `bin` 或依赖时，才需要重新 `npm link`。

### 卸载

```powershell
npm uninstall -g @fxdevkit/cli
```

> 若 Windows 下残留（`npm link` 偶发清不掉符号链接），手动删：
> `%APPDATA%\npm\node_modules\@fxdevkit` 目录，以及 `%APPDATA%\npm\fxdevkit`、`fxdevkit.cmd`、`fxdevkit.ps1` 三个 shim 文件。


## 二、命令总览

| 命令 | 作用 |
| --- | --- |
| `fxdevkit status` | 查看当前状态：fxdevkit 版本、当前仓库、hooks 托管情况、插件及版本 |
| `fxdevkit doctor` | 检查增强链路是否正常（Node / Git / 仓库 / hooks / 插件加载） |
| `fxdevkit install` | 在当前 git 仓库托管 git hooks，让提交动作可被插件增强 |
| `fxdevkit uninstall` | 取消当前仓库的 hooks 托管 |
| `fxdevkit self version` | 查看 fxdevkit 自身版本 |
| `fxdevkit self update` | 更新 fxdevkit 到最新版 |
| `fxdevkit self rollback <version>` | 回退 fxdevkit 到指定版本 |
| `fxdevkit self uninstall` | 卸载 fxdevkit 自身 |
| `fxdevkit plugin list` | 列出插件及版本、hooks、permissions |
| `fxdevkit plugin add <pkg>` | 安装插件（`npm install` 到用户目录） |
| `fxdevkit plugin remove <pkg>` | 移除插件 |
| `fxdevkit plugin enable <id>` | 启用插件 |
| `fxdevkit plugin disable <id>` | 停用插件 |
| `fxdevkit config show` | 打印合并后的生效配置（含各层来源） |
| `fxdevkit config validate` | 校验各插件配置是否合法 |
| `fxdevkit report` | 统计本地事件记录 |
| `fxdevkit help` | 显示本帮助 |

## 三、核心命令详解

### `fxdevkit status`

查看当前状态：版本、当前仓库、hooks 是否托管、插件列表。

```bash
$ fxdevkit status
[fxdevkit] @fxdevkit/cli 0.1.0 · Node v22.22.2
[fxdevkit] 仓库 D:/products/devkit
[fxdevkit] hooks 已托管
[fxdevkit] 插件:
  commit        commit-rules@0.1.0            ok
```

### `fxdevkit doctor`

一次自检，任何一项未通过时相关增强不会发生，并以退出码 `1` 退出。

```bash
$ fxdevkit doctor
[fxdevkit] Node                v22.22.2                                          ok
[fxdevkit] Git                 git version 2.55.0.windows.3                      ok
[fxdevkit] 仓库                D:/products/devkit                                ok
[fxdevkit] hooks 托管          D:\Users\yin.huang\.fxdevkit\hooks                  ok
[fxdevkit] 入口有效            D:\products\devkit\packages\cli\dist\index.js     ok
[fxdevkit] 插件 commit-rules   加载成功                                          ok
[fxdevkit] 全部检查通过，增强链路正常
```

### `fxdevkit install` / `fxdevkit uninstall`

在**当前 git 仓库**内执行。

- `install`：设置 `core.hooksPath` 指向 fxdevkit 的 hooks 目录，以后 `git commit` / `git push` 等动作会被插件增强。
- `uninstall`：取消托管，恢复 git 默认行为。

```bash
$ fxdevkit install
[fxdevkit] hooks 目录：D:\Users\yin.huang\.fxdevkit\hooks
[fxdevkit] 已托管：commit-msg ...
```

### `fxdevkit self ...`

管理 fxdevkit 自身（通过 `npm` 全局安装的 `@fxdevkit/cli`）。

```bash
fxdevkit self version              # 查看版本
fxdevkit self update               # 更新到 @fxdevkit/cli@latest
fxdevkit self rollback 0.1.0       # 回退到指定版本
fxdevkit self uninstall            # 卸载 fxdevkit 自身
```

## 四、插件命令

插件通过短名（`name`）路由，命令形式为 `fxdevkit <插件name> <命令>`。
CLI 源码不硬编码任何插件 id。

### 查看插件版本

```bash
$ fxdevkit commit -v
commit-rules@0.1.0
  name:    commit
  dir:     D:\products\devkit\node_modules\@fxdevkit\plugin-commit-rules
  命令:    check
```

### 查看插件帮助

```bash
$ fxdevkit commit --help
fxdevkit commit — commit-rules@0.1.0

用法:
  fxdevkit commit check
```

### 执行插件命令

```bash
fxdevkit commit check          # 触发 commit-rules 插件的 check 命令
```

> 插件未提供某命令时会提示，不会静默通过。

## 六、配置与事件

```bash

fxdevkit config validate   # 校验各插件配置
```

```bash
    { "name": "env",    "applied": true }
  ],
  "config": { ... }
}
```

## 七、环境变量

| 变量 | 说明 |
| --- | --- |
| `FXDEVKIT_HOME` | 覆盖全局目录（默认 `~/.fxdevkit`） |
| `FXDEVKIT_SERVER_URL` | 指向真实 Server；设置后自动关闭 mock |
| `FXDEVKIT_SERVER_MOCK=1` | 强制使用本地 mock Server |
| `FXDEVKIT_TELEMETRY=0` | 关闭事件落盘 |
| `FXDEVKIT_HOOK_TIMEOUT_MS` | 单个插件在 hook 中的硬超时（默认 `1000`） |
| `FXDEVKIT_DEBUG=1` | 输出调试日志 |

## 八、目录结构

fxdevkit 的用户级目录默认在 `~/.fxdevkit`（可用 `FXDEVKIT_HOME` 覆盖）：

```
~/.fxdevkit/
├── config.yaml      # 内核核心配置（插件启用、Server、hooks 行为）
├── hooks/           # 分发的 git hook 脚本
├── plugins/         # 插件安装目录（npm 包）
├── events/          # 事件落盘记录
├── cache/           # 缓存
└── package.json     # 插件依赖清单
```

> 职责划分：`~/.fxdevkit/` 放内核核心配置；项目特有的增强规则放在各仓库的 `.fxdevkit.yaml`。

## 九、常见问题

- **`doctor` 有一项失败**：相关增强不会发生。常见如 `hooks 托管` 失败 → 在当前仓库执行 `fxdevkit install`。
- **插件未加载**：执行 `fxdevkit plugin list` 查看是否被 `SKIPPED`，以及 `fxdevkit config validate` 校验配置。
- **卸载 / 更新 fxdevkit 自身**：见 `fxdevkit self uninstall` / `fxdevkit self update`。
