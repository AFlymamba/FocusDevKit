人的能力增强器

不断增强你的个人助手

它住在你的电脑里，把重复的事接过去——提交规范、格式检查、日志查找。 决定仍然归你，习惯也不必改。

npm install -g @fxdevkit/cli && fxdevkit install --global

一次安装，已存在的仓库和以后新建的仓库都会生效。

越用越顺手的三个原因

不断增强

需要什么能力，就装什么插件。装一个，多一份力气；不想要了，随时卸下。

完全属于你

装什么、用在哪，由你决定。配置跟着人走，换机器也还在。

从不打断

增强失效时静默让行。它宁可没帮上忙，也不会挡你的路。

它现在会做什么

commit-rules

提交时自动给 commit message 补上团队约定的前缀。你照常敲 git commit，前缀由它加上。
